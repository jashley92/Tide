# What's new in v1.15.0

A release for administrators: how TIDE introduces itself to the sites it reads, and more patience with NVD.

## Administrators

- **User agent.** Administration › Sources has a *User agent* card: TIDE's own (the default, which now names the release), a current desktop browser, or a string of your own. A source's form can override it for that source, for a feed that turns TIDE away.
- **NVD gets longer.** CVE enrichment waits up to 60 seconds for NVD (`Cve:NvdTimeoutSeconds`) and tries twice more before giving up. The refresh no longer holds up feed polling, and Diagnostics and the Sources card show while it runs.
- **Editing a source** brings its form into view, and the sources table stays inside a narrow window.
